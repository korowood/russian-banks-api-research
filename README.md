| **FX spot** | **частично** | (1) Sber API: поручения на покупку/продажу валюты для корп. клиентов; (2) SberCIB Terminal API — SPOT для FI/крупного бизнеса | [Conv currency overview](https://developers.sber.ru/docs/ru/sber-api/scenarios/ved/conv-currency/overview); SberCIB: заявлено API, **публичной OpenAPI-спеки не найдено** | Юрлица, клиент Сбера; scope `CONVERSION_OPERATION_CURRENCY`; CIB — договор / лицензия FI |

| **Transactions** | **есть** | Open API / partner B2B (наборы «Компаниям», «Холдингам», платформы) | Платёжные поручения, выписки, СБП, зарплатный проект — в [overview Sber API](https://developers.sber.ru/docs/ru/sber-api/start/overview) | Клиент СберБизнес; ЭП; договор на scope |
| **Прочее** | **есть** | Публичный portal + sandbox | ВЭД/валютный контроль, бизнес-карты, эквайринг, самозанятые, инкассация, безопасные сделки | Юрлица/ИП РФ |

### Контекст: Open Banking в РФ

Стандарты и спецификации ведутся через **Ассоциацию ФинТех** и материалы ЦБ ([wiki.openbankingrussia.ru](https://wiki.openbankingrussia.ru/ru/specifications), документы ЦБ по счетам/переводам). На момент ресерча внедрение носит в основном **пилотный / рекомендательный** характер; наличие «Open Banking» у банка ≠ публичный developer portal по всем treasury-категориям.

## 4. Краткие выводы

1. **По размеру** устойчивый топ: Сбер → ВТБ → ГПБ → Альфа; далее ПСБ / Т-Банк / РСХБ / МКБ / ДОМ.РФ / Совкомбанк (порядок чуть плавает между источниками и датами).
2. **Самые зрелые публичные API-экосистемы:** **Т-Банк** (Business T-API + T-Invest) и **Сбер** (Sber API + заявленный CIB Terminal API); сильный корпоративный контур у **Альфы** (Alfa API + H2H + брокерский PRO API).
3. **Treasury-класс (FX spot/swap/forward, repo, cap/floor)** почти ни у кого не опубликован как полный self-serve Open API: обычно **казначейский терминал / H2H / договор с банком**. Исключения по кускам: Сбер (conv + CIB), ВТБ (eFX), ГПБ/Альфа (конверсия в H2H).
4. **Brokerage API с облигациями:** публично подтверждены у **Т-Инвестиций** и **Альфа-Инвестиций PRO**; у Сбера/ВТБ публичного аналога **не найдено**.
5. Где данных нет — в отчёте явно указано **«не найдено публично»**; отсутствие в открытых источниках не означает отсутствие закрытых интеграций у банка.
